# 🖥️ zhmon — 飞牛NAS 中文系统监控

一个用 Python 写的**全中文**终端系统监控工具，专为 [飞牛 fnOS](https://www.fnos.com.cn/) NAS 打造，当然任何 Linux 系统都能用！

> btop / glances / htop 这些终端监控工具都只有英文界面，zhmon 就是来填这个坑的——**界面 100% 中文**，开箱即用。

## ✨ 功能

- ⚙️ **CPU**：总使用率 + 每个核心实时利用率
- 🧠 **内存**：使用率、已用/总量、交换分区
- 💾 **磁盘**：每个存储卷的使用率与容量
- 🌡️ **温度**：CPU 各核心、主板、固态盘、芯片组温度
- 🌐 **网络**：实时上传/下载速度
- 🎨 彩色进度条 + 告警变色（>70% 黄，>90% 红；温度 >65°C 黄，>75°C 红）
- ⏱️ 每秒自动刷新

## 📦 安装

```bash
# Debian/Ubuntu 系
sudo apt install python3-psutil python3-rich

# 下载脚本
sudo curl -o /usr/local/bin/zhmon https://raw.githubusercontent.com/senxppp/zhmon/main/zhmon.py
sudo chmod +x /usr/local/bin/zhmon

# 其他发行版用 pip
pip install psutil rich
```

## 🚀 使用

```bash
zhmon
```

按 `Ctrl+C` 退出。
